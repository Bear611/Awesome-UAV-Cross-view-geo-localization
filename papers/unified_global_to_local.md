| [Towards Active Cross-View Object Geo-Localization](http://arxiv.org/abs/2609.19662v1) | This paper addresses the limitation that conventional cross-view object geo-localization (CVOGL) relies on a fixed UAV query image, overlooking the mobility of embodied agents. It introduces Active Cross-View Object Geo-Localization (ActiveGeo), in which a UAV agent sequentially selects new informative viewpoints and decides when to stop, aiming to improve localization with minimal observations. The authors propose ActiveMoPT, a three-stage framework built upon MoPT: (1) Multi-View Prompt-Preserving Adaptation, which introduces a shared multi-view cross-attention module and a Preserve-Improve loss so that the model can aggregate additional UAV views while reusing the initial target prompt; (2) Trajectory-Guided Policy Initialization, which uses oracle trajectories under a frozen localizer to supervise a stop head and a 54-way view-selection head; and (3) Cost-Aware Policy Refinement, which applies GRPO with a gain-cost reward to balance localization improvement against the cost of acquiring extra views. The paper also constructs ActiveGeo-858, a zero-shot test set of 858 scenes and 1,716 target annotations built from the GeoText-1652 test split. On the MoP-UAV benchmark, ActiveMoPT is reported to outperform prior passive CVOGL methods, reaching 0.384 mIoU under the point-prompt protocol while using only 1.291 views on average, and 0.414 mIoU / 0.478 Acc@0.50 under the P+B+L prompt combination using 1.450 views. Under zero-shot evaluation on ActiveGeo-858, ActiveMoPT is reported to substantially improve over MoPT across point, box, and P+B prompt settings. | MoP-UAV, ActiveGeo-858 | - |
| [RIM: A Retrieval-In-Matching framework for cross-domain global visual localization of UAVs](https://doi.org/10.1016/j.knosys.2026.117027) | RIM (Retrieval-In-Matching) addresses cross-domain global visual localization for unmanned aerial vehicles (UAVs), where real UAV imagery must be matched against a reference map rendered from photogrammetric 3D meshes (Google 3D Tiles or self-reconstructed SfM). Differences in acquisition time, imaging platform, and viewpoint between UAV and reference imagery create substantial appearance and geometric shifts that make robust 6-DoF pose estimation under unreliable GNSS difficult. To mitigate this, the authors render UAV-viewpoint references by sampling Google 3D Tiles across positions, altitudes, and orientations, providing pose-near positives and geographically distant hard negatives for two-stage cross-domain adaptation of SALAD. The proposed RIM architecture freezes the adapted DINOv2-B retriever and distills a local-descriptor decoder (DeDoDe-style) from its token field combined with shallow VGG19 features. A frozen SALAD aggregation head and the distilled local decoder therefore consume the same DINOv2-B token field, so one shared backbone forward per query supports both global retrieval and local geometric re-ranking. Two zero-shot benchmarks are used: a reconstructed EPFL Urbanscape dataset (3,158 real UAV queries against 17,400 rendered references) and a self-collected Chang'an Park dataset (2,315 queries after a 68-frame construction exclusion, against 26,568 SfM-rendered references), both geographically disjoint from the Urbanscape-OOP fine-tuning split. Reported effects: under the full 3D distance metric at 25/50 m, RIM's improves Recall@1 over SALAD by 8.55/13.77 percentage points on Urbanscape and 4.45/8.94 points on Park, and the online query path through retrieval, candidate matching, and robust geometric verification at Top-K=5 takes 90.8 ms. | Urbanscape (EPFL reconstructed, 3D Tiles), Chang'an Park (self-collected, SfM mesh), Urbanscape-OOP (fine-tuning split) | [Code](https://github.com/curious-energy/RIM) |
| [Multi-View Mixture-of-Experts with Vision-Language Reranking for Cross-View Object Geo-Localization](http://arxiv.org/abs/2609.18139v1) | This paper addresses Cross-View Object Geo-Localization (CVOGL), where a target object must be localized within satellite imagery using drone (UAV) or street-view (SVI) query images. Existing detectors are trained separately per viewpoint, causing parameter redundancy and limiting cross-view knowledge sharing, while top-ranked satellite candidates are often visually indistinguishable and cannot be disambiguated by appearance or class labels alone. To overcome these limitations, the authors propose MVLGeo, a unified multi-view framework built on three components: (1) a Vision-Language Reranking (VL-Rerank) stage that uses environmental context descriptions generated by Qwen-VL-Chat from the query view and an InternVL-based comparator to rerank candidates; (2) a Multi-View Mixture-of-Experts (MV-MoE) architecture with a shared ResNet18 encoder, identity-initialized view-specific residual experts, and cross-view contrastive (InfoNCE) alignment, replacing per-view detectors with a single 91.0M-parameter model; and (3) an ESAM-Prior, an instance-adaptive anisotropic Gaussian heatmap derived from SAM-segmented masks fitted with oriented ellipses, used as shape-aware positional encoding. Experiments are conducted on the CVOGL benchmark with both UAV and SVI queries against satellite imagery. The authors report state-of-the-art Drone-to-Satellite Acc@50 of 66.04% on the test set with one unified model, versus prior methods requiring two independent detectors, achieving a 38% reduction in total parameters. | CVOGL | - |
| [URF-Loc: Uncertainty-Aware Frequency-Spatial Network for GNSS-Denied UAV Geo-Localization](https://doi.org/10.1007/978-981-92-3504-9_20) | URF-Loc addresses cross-view geo-localization for UAVs operating under GNSS-denied conditions, where severe appearance variations, large search spaces, and ambiguous structural correspondence make robust localization difficult. The paper observes that prior approaches either rely on global retrieval with limited spatial precision or on deterministic dense prediction without modeling prediction reliability, leading to unstable localization. To address this, the authors propose a coarse-to-fine framework. The coarse stage employs a spatial-frequency joint (FSJ) representation that injects high-frequency residuals into multi-scale features to enhance view-invariant structural cues for robust global matching. The refinement stage introduces an uncertainty-aware regression (UAR) module that formulates localization as heteroscedastic probabilistic regression, enabling adaptive handling of ambiguous regions and providing reliable uncertainty estimates. Experiments are conducted on the UAV-VisLoc benchmark, where URF-Loc is reported to achieve state-of-the-art performance, significantly improving meter-level accuracy and bounding-box quality while providing reliable uncertainty estimation. | [Unifying UAV Cross-View Geo-Localization via 3D Geometric Perception](http://arxiv.org/abs/2604.01747v1) | This paper addresses UAV cross-view geo-localization in GNSS-denied environments, where severe geometric discrepancy between oblique UAV imagery and orthogonal satellite maps undermines robust matching. Most prior pipelines treat coarse place retrieval and fine pose estimation as decoupled stages, treating perspective distortion as appearance noise. The authors propose a unified, geometry-aware framework that reconstructs a local 3D scene from multi-view UAV sequences using a Visual Geometry Grounded Transformer (VGGT) and renders a satellite-aligned Bird's-Eye View (BEV) that serves as a geometric intermediary between retrieval and pose regression. A Satellite-wise Attention Block isolates the interaction between each satellite candidate and the reconstructed UAV scene, preventing inter-hypothesis interference while reducing computational complexity from quadratic to linear in the number of candidates. A dual validation strategy combining geometric and feature-similarity criteria selects the optimal satellite reference for 3-DoF pose refinement (latitude, longitude, heading). The authors also release a recalibrated University-Pose extension of University-1652 with explicit 3-DoF pose annotations and an IoU-based retrieval protocol. Experiments on University-Pose/University-1652 and SUES-200 report that the Refined BEV variant achieves R@1 of 79.0 on University-1652 and 68.0 on SUES-200 (150 m), substantially outperforming reported SOTA baselines while enabling meter-level positioning within retrieved tiles. | University-1652, University-Pose (recalibrated extension of University-1652), SUES-200 | [Code](https://github.com/Collebt/Uni-CVGL) |

In the first stage, ternary quantized transformers are adapted to the cross-view domain through progressive transfer learning, enabling compact global image retrieval without relying on large-scale pretraining. Experiments on public cross-view datasets demonstrate improved localization accuracy alongside reduced computational cost, and the authors highlight the framework's suitability for deployment on resource-constrained UAV platforms. | [GRiM-Net: A Two-Stage Cross-View Visual Localization Framework for UAVs](https://doi.org/10.3390/rs18101477) | GRiM-Net addresses GNSS-denied autonomous UAV flight by proposing a two-stage, jointly optimized cross-view visual localization framework that couples coarse global retrieval with pixel-level fine matching. The pipeline first runs a global retrieval module that aggregates deep features to rank candidate satellite-map patches from a pre-built index, narrowing localization from a full aerial map to a local region. A fine matching module then performs joint keypoint detection and description on both the UAV query and the retrieved satellite candidate, followed by bidirectional correspondence matching and weighted homography estimation that maps the image center into geographic coordinates. Both stages share a backbone with domain-adaptive batch normalization and are trained end-to-end with a triplet loss for retrieval together with keypoint, descriptor, and homography reprojection losses for matching, producing synergistic feature representations. Experiments are conducted on public urban cross-view benchmarks and show that GRiM-Net delivers efficient and robust geographic coordinate regression suitable as a practical component for broader UAV navigation systems. The authors evaluate the framework through dataset assessments and real-world flight experiments, reporting trajectory accuracy approaching low-accuracy GPS and operating frequency comparable to classic VO methods. | [Exploring the best way for UAV visual localization under Low-altitude Multi-view Observation Condition: a Benchmark](https://arxiv.org/abs/2503.10692) | This paper introduces a benchmark for UAV Absolute Visual Localization (AVL) under low-altitude (<300m) multi-view (pitch angles 20°–90°) conditions, where extreme viewpoint changes challenge conventional nadir-view methods. The authors construct AnyVisLoc, a large-scale dataset of 18,000 UAV images captured by seven DJI drone types across 15 cities, 25 regions, and multiple altitudes, with both aerial photogrammetry and historical satellite reference maps plus DSM data. A unified coarse-to-fine framework integrates image-level retrieval (template matching, NetVLAD, drone-to-satellite deep networks), pixel-level matching (handcrafted, sparse/dense learning-based), and PnP+RANSAC pose solving, evaluated under four localization strategies.
